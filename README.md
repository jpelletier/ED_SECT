# ED_SECT
This is a program running on DOS on a PC XT for a PPIDE ISA card.  

The software uses the hardware directly.  
-gets and displays disk info  
	-Serial Number  
	-Model Number/Name  
	-Total # LBA Sectors  
-binary editor access to every sector
To compile, I used Borland turbo C++ v3 running on DOSEMU2
